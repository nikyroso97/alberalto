# Alberalto · Il taccuino di Leo

Gioco per bambini (5-10 anni) ambientato ad Alberalto, l'albero grande come una montagna: si esplora il Borgo delle Radici, si fanno esperimenti nel laboratorio di Bip e si scrivono le scoperte nel taccuino per riaccendere il Faro della Memoria.

- Si gioca dal browser del telefono (meglio in orizzontale) e si può aggiungere alla schermata Home: poi funziona anche senza internet.
- Nessun dato raccolto, nessuna pubblicità, nessun acquisto.

Dopo ogni modifica: `python3 crea-sw.py`, poi commit e push.
